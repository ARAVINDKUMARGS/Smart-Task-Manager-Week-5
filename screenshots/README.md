## 💻 How to Capture High-Quality Screenshots

### On Windows 10 / 11:
1. Open `index.html` in your browser (Google Chrome or Microsoft Edge recommended).
2. Press `F11` to enter clean full-screen mode, or zoom to 100% (`Ctrl + 0`).
3. Press `Windows Key + Shift + S` to open the Windows Snipping Tool.
4. Select **Window Snip** or **Rectangular Snip** to capture the application window.
5. Save the image into this `screenshots/` folder matching the filenames above.

### Chrome DevTools Device Mode (For Responsive Mobile View):
1. Press `F12` or `Ctrl + Shift + I` to open Developer Tools.
2. Click the **Toggle device toolbar** button (`Ctrl + Shift + M`).
3. Select **iPhone 14 Pro** or **iPad Air** to capture responsive layout screenshots.
4. In the DevTools three-dots menu (top-right of viewport), click **Capture full size screenshot**.
